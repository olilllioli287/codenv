codenv 程式練習環境(macOS)
vim 寫程式、按 F10 看執行結果;畫面可選兩格或三格(三格多一格放 AI 或終端機)
圖文版安裝手冊:https://claude.ai/artifact/5K4MCZhcnMFUFyY8qmifeb
GitHub:https://github.com/olilllioli287/codenv


======================================================================
安裝順序(一定要照這個順序,前面的沒裝好,後面的會裝不起來)
======================================================================

  第 1 步 編譯器(Command Line Tools)   ← 最先裝,其他東西都需要它
  第 2 步 Homebrew                       ← 需要第 1 步;第 3、4 步要靠它來裝
  第 3 步 tmux                           ← 需要第 2 步
  第 4 步 iTerm2                         ← 需要第 2 步
  第 5 步 codenv 設定                    ← 需要第 1~4 步都完成,而且要在 iTerm 裡做
  第 6 步 讓 F9、F10 可以直接按
  第 7 步 第一次使用

開始前:
  - 電腦接上電源、連上穩定的 Wi-Fi。第 1、2 步要下載 1~2 GB,可能要 20~60 分鐘。
  - 要知道這台 Mac 的開機密碼。輸入密碼時畫面不會出現任何字(連 * 都沒有),
    這是正常的,打完直接按 Enter。
  - 一次只貼一行指令,等它跑完、出現新的一行 % 再貼下一行。跑的時候不要打其他字。


----------------------------------------------------------------------
第 1 步 安裝編譯器(Command Line Tools)        約 10~30 分鐘
----------------------------------------------------------------------
為什麼先裝:它負責把 C++ 翻譯成電腦能執行的程式,也附帶 git 等工具。
            第 2 步的 Homebrew 沒有它就裝不起來。

 1. 打開「終端機」:按 ⌘Cmd + 空白鍵,輸入「終端機」或 Terminal,按 Enter。
 2. 貼上這行,按 Enter:
        xcode-select --install
 3. 畫面會跳出一個小視窗,按「安裝」,再按「同意」。
 4. 等進度條跑完,出現「已安裝軟體」後按「完成」。

確認有裝好:回到終端機執行
        clang++ --version
    看到 Apple clang version ... 就成功了。

如果出現「Command line tools are already installed」:代表本來就裝過了,直接做第 2 步。


----------------------------------------------------------------------
第 2 步 安裝 Homebrew                          約 5~15 分鐘
----------------------------------------------------------------------
為什麼要裝:Homebrew 是 Mac 上「用一行指令安裝軟體」的工具,第 3、4 步都要用它。
必須先完成:第 1 步。

 1. 在終端機貼上這一整行,按 Enter:
        /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
 2. 出現 Password: 時,輸入開機密碼(畫面不會顯示),按 Enter。
 3. 出現 Press RETURN/ENTER to continue 時,按 Enter。
 4. 接著會跑很多英文字,什麼都不要按,等到出現 ==> Installation successful!
 5. 【最重要,很多人漏掉】成功訊息下面有一段 ==> Next steps:,裡面有兩三行指令。
    要把那幾行複製下來,貼上執行,不然終端機會找不到 brew。
    M 系列晶片的 Mac 通常是這三行(以你畫面上顯示的為準):
        echo >> ~/.zprofile
        echo 'eval "$(/opt/homebrew/bin/brew shellenv zsh)"' >> ~/.zprofile
        eval "$(/opt/homebrew/bin/brew shellenv zsh)"

確認有裝好:
        brew --version
    看到 Homebrew 4.x.x 就成功了。

如果出現 command not found: brew:代表第 5 點的 Next steps 還沒執行,執行完再試一次。


----------------------------------------------------------------------
第 3 步 安裝 tmux                              約 1~3 分鐘
----------------------------------------------------------------------
為什麼要裝:tmux 負責把一個視窗切成兩格或三格。
必須先完成:第 2 步。

 1. 在終端機執行:
        brew install tmux

確認有裝好:
        tmux -V
    看到 tmux 3.x 就成功了。


----------------------------------------------------------------------
第 4 步 安裝 iTerm2                            約 1~3 分鐘
----------------------------------------------------------------------
為什麼要裝:iTerm2 是比較好用的終端機 App。codenv 的按鍵(例如 ⌘Cmd + ←)
            是照 iTerm 設計的,之後都用 iTerm 取代內建的「終端機」。
必須先完成:第 2 步。

 1. 在終端機執行:
        brew install --cask iterm2
 2. 到「應用程式」資料夾找到 iTerm,點兩下打開。
    如果出現「這是從網際網路下載的 App,確定要打開嗎?」,按「打開」。

確認有裝好:iTerm 打得開就成功了。從這裡開始,把內建的「終端機」關掉,改用 iTerm。


----------------------------------------------------------------------
第 5 步 安裝 codenv 設定                       約 1 分鐘
----------------------------------------------------------------------
必須先完成:第 1~4 步。這一步要在 iTerm 裡做。

 1. 在 iTerm 貼上這一整行,按 Enter:
        zsh -c "$(curl -fsSL https://raw.githubusercontent.com/olilllioli287/codenv/main/get.sh)"
 2. 看到這幾行就成功了:
        已安裝 ~/.vimrc
        已安裝 ~/.tmux.conf
        已安裝 ~/.codenv.zsh
        已在 ~/.zshrc 加上 source ~/.codenv.zsh
        完成。……
 3. 按 ⌘Cmd + Q 完全關掉 iTerm,再重新打開,新設定才會生效。

原本就有的 ~/.vimrc、~/.tmux.conf 會先自動備份成「檔名.bak-日期時間」,不會不見。
最後如果出現「還缺 tmux」或「還缺編譯器」,代表第 1 步或第 3 步沒裝好,回去補裝,
再重新執行一次上面那行。


----------------------------------------------------------------------
第 6 步 讓 F9、F10 可以直接按                  約 1 分鐘
----------------------------------------------------------------------
MacBook 最上面那排鍵預設是調亮度、音量。直接按 F10 其實是「靜音」,不會執行程式。
選一種解法:
  A. 每次都一起按住 fn(左下角有地球圖示那顆),例如 fn + F10。
  B. 系統設定 → 鍵盤 → 鍵盤快速鍵… → 左邊選「功能鍵」→
     打開「將 F1、F2 等鍵作為標準功能鍵使用」。
     改了以後,要調音量反而要按 fn。


----------------------------------------------------------------------
第 7 步 第一次使用
----------------------------------------------------------------------
 1. 打開 iTerm,輸入 codenv 按 Enter。
    第一次會先問畫面要幾格:
      2 = 兩格:左邊寫程式、右邊看執行結果(沒有用 AI 的話選這個)
      3 = 三格:左邊放 AI 或終端機,右上寫程式、右下看執行結果
    選完會記住,之後不會再問。想換的話輸入 codenv layout。
 2. 第一次還沒有資料夾:按 n、Enter,輸入資料夾名稱(例如 cpp),按 Enter。
 3. 輸入資料夾前面的數字(例如 1),按 Enter。
 4. 選檔案:按 n、Enter,輸入 hello.cpp,按 Enter。
 5. 畫面會照你選的格數切好,vim 已經打開。
 6. 按 i 開始打字(左下角出現 -- INSERT --),打完按 Esc。
 7. 按 F9 存檔並檢查有沒有打錯;按 F10 編譯並執行,結果出現在執行結果那格(兩格在右邊、三格在右下)。
 8. 在執行結果那格按 Esc,會跳回 vim。

程式放在 ~/programming_language 底下,執行檔會放在同一個資料夾裡的 bin。


======================================================================
常用按鍵
======================================================================
  vim 裡(一般模式):
    i            開始打字          Esc         停止打字
    F9           存檔+檢查錯誤     F10         存檔+編譯+執行
    Ctrl+S       存檔              Ctrl+Z      復原(Ctrl+Y 重做)
    :q           關掉 vim
  vim 裡(打字時也能用,跟 Windows 上的編輯器一樣):
    滑鼠拖曳、雙擊,或 Shift+方向鍵   選取文字;選取後直接打字會取代它
    Ctrl+C / Ctrl+X / Ctrl+V         複製 / 剪下 / 貼上(跟 Mac 共用剪貼簿)
    Tab / Shift+Tab                  選取多行時整塊增加 / 減少縮排
    Ctrl+F                           搜尋,按 Enter 跳過去,再按 n 找下一個
    打 ( [ " 會自動補上另一半;打 { 再按 Enter 會自動補上 }
    :q!          不存檔直接關掉
  執行結果那格:
    Esc          跳回 vim          Ctrl+C      強制停止跑不完的程式
  tmux(先按 Ctrl+A,放開,再按下一個鍵):
    |  左右切格    -  上下切格    h j k l  移到左/下/上/右那格    x  關掉這格
  滑鼠:點一下切換格子,滾輪捲動,拖曳分隔線調整大小。
        vim 以外的格子想反白複製文字時,要按住 Option 再拖曳,再按 Cmd+C。


======================================================================
選用設定
======================================================================
換畫面格數:輸入 codenv layout 重新選,或直接輸入 codenv layout 2 / codenv layout 3。
  下次開 codenv 就會用新的排法。
三格時左邊自動開 AI:在 iTerm 執行 open -e ~/.codenv.zsh,
  把 CODENV_AI='' 改成例如 CODENV_AI='claude',存檔後重開 iTerm。
換成一樣的配色:iTerm → Settings → Profiles → 左下 Other Actions →
  Import JSON Profiles,在選檔案的視窗按 ⌘Cmd + Shift + G,
  輸入 ~/.codenv-kit/iterm-profile.json。匯入後選中 codenv,
  再按 Other Actions → Set as Default。

更新
======================================================================
再執行一次第 5 步那一行就好。原本的設定會自動備份;
你在 ~/.codenv.zsh 設定過的資料夾位置和 AI 指令會保留。
做完把開著的 vim 關掉再打開。


======================================================================
換回舊版
======================================================================
  ls ~/.vimrc.bak-*                       列出備份檔,看日期時間
  cp ~/.vimrc.bak-日期時間 ~/.vimrc        把想要的那份複製回來,再重開 vim
(~/.tmux.conf、~/.codenv.zsh 的備份也是同樣的方法)
