codenv 說明

Mac 上寫 C++ / Python 作業的終端機環境
vim 寫程式，按 F10 看執行結果

開始使用

  1. 打開 iTerm，輸入 codenv 按 Enter。
  2. 輸入數字選資料夾和檔案；按 n 可以新增（檔名要有副檔名，例如 hw1.cpp）。
  3. 畫面會分好：寫程式的 vim，和看執行結果的那一格。按 i 開始打字，打完按 Esc。
按鍵做什麼
F9存檔並檢查有沒有打錯；錯的那行畫紅色底線，訊息直接寫「第幾行」
F10存檔、編譯、執行，結果顯示在旁邊那格
Esc（在結果那格）跳回 vim
Ctrl+S / Ctrl+Z / Ctrl+Y存檔 / 復原 / 重做
Ctrl+C / Ctrl+V複製 / 貼上（在結果那格，Ctrl+C 是停止跑不完的程式）
:q / :q!關掉 vim / 不存檔直接關掉
codenv layout重新選畫面要兩格還是三格

Windows 上 Dev-C++ 的寫法照樣能跑：#include <bits/stdc++.h>、system("pause")，Big5 的中文也不會變亂碼。要存很大的整數，請用 long long（Windows 上的 long 比 Mac 小）。

F9、F10 要怎麼按

MacBook 最上面那排鍵預設是調亮度、音量，直接按 F10 其實是「靜音」。選一種：

  • 每次一起按住 fn（左下角有地球圖示那顆），例如 fn + F10。
  • 改成預設就是 F 鍵：系統設定 → 鍵盤 → 鍵盤快速鍵… → 功能鍵 → 打開「將 F1、F2 等鍵作為標準功能鍵使用」。改了以後，調音量、亮度反而要按 fn，所以要不要改由你決定。

更新 codenv

在 iTerm 執行這一行（第一次安裝也是同一行，缺什麼會自動裝）：

zsh -c "$(curl -fsSL https://raw.githubusercontent.com/olilllioli287/codenv/main/get.sh)"

完整說明、常見問題：olilllioli287.github.io/codenv

可以另外裝的外掛（自由選配）

都不是必要的，不裝也能正常使用 codenv。想裝哪個就照它的說明裝。

tmux 中文優化 tmux-kit

Ctrl+A 連按兩次叫出中文選單：分割、關掉、放大格子，開分頁、取名，把格子搬到別的分頁、換排列方式。同一包裡還有「Claude Code 回覆完，那個分頁反白提醒」。

github.com/olilllioli287/tmux-kit

tmux 排版優化 實驗中・tmux-kit

在 iTerm 裡按 Cmd+Ctrl+A，開一個視窗，把所有分頁和格子畫成小縮圖，用滑鼠拖曳就能排好。還在測試，拖曳不一定每次都成功。安裝 tmux-kit 時第 2 項選要裝。

github.com/olilllioli287/tmux-kit

image-shelf Claude Code 外掛

在 Claude Code 貼上的圖片，排在輸入框上方顯示成真正的縮圖；點一下就能畫圈、加箭頭、寫字、裁切。iTerm2 和 tmux 裡也看得到。

github.com/olilllioli287/claude-code-image-shelf

ShotLine 截圖小工具

截圖先掛在螢幕上方的曬衣繩上，點一下就能標示，過一會兒自動收進截圖檔案夾。macOS 14 以上。改自 Alejandro Buján 的 Tendedero（MIT 授權）。

github.com/olilllioli287/ShotLine

tmux-kit 的安裝（三樣各自選要不要裝）：

zsh -c "$(curl -fsSL https://raw.githubusercontent.com/olilllioli287/tmux-kit/main/get.sh)"

image-shelf 的安裝（在 Claude Code 的輸入框打）：

/plugin install image-shelf --marketplace olilllioli287/claude-code-image-shelf
